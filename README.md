🏦 Bank Management System

A console-based Bank Management System developed using Python Object-Oriented Programming (OOP) concepts. This project demonstrates the practical implementation of OOP principles through a simple banking application.

📌 Features

- Create Savings and Current Accounts
- Deposit Money
- Withdraw Money
- Display Account Details
- Display All Accounts
- Calculate Account Interest
- Validate User Inputs
- Prevent Duplicate Account Numbers

🛠️ Technologies Used

- Python 3
- Python Standard Library ("abc" module)

🧠 OOP Concepts Implemented

Concept| Implementation
Classes and Objects| Bank, BankAccount and child classes
Constructor| "__init__()"
Encapsulation| Private attribute ("__balance")
Inheritance| SavingsAccount and CurrentAccount
Polymorphism| "calculate_interest()"
Abstraction| ABC and "@abstractmethod"
Method Overriding| "display_details()"
Composition| Bank manages account objects
"super()"| Accessing parent class methods

▶️ How to Run

1. Clone the repository

git clone https://github.com/Beebijan-cse/Bank-Management-System.git

2. Navigate to the project folder

cd Bank-Management-System

3. Run the application

python main.py

📋 Application Menu

1. Create Account
2. Deposit Money
3. Withdraw Money
4. Display Account
5. Display All Accounts
6. Exit

⚠️ Note

This is an educational project developed to practise Python OOP concepts. Account information is stored in memory and will be lost when the program exits. It is not intended for real banking transactions.
